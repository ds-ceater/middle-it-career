# 記事の追加手順

## 全体の流れ

1. `npm run new:article -- <フォルダ名> "タイトル"` で記事フォルダを作る
2. 画像を用意して、記事フォルダに置く
3. 本文を書く（`npm run dev` で確認しながら）
4. `draft: false` にする
5. `npm run build` が通ることを確認する
6. トップページなどからリンクを張る（必要な場合）
7. `main` に push → GitHub Actions が本番に反映

---

## 1. 記事フォルダを作る

```bash
npm run new:article -- resume-writing "職務経歴書の書き方"
```

次のフォルダとファイルができる。

```
src/content/articles/resume-writing/
  index.mdx        ← 本文（docs/templates/article.mdx のコピー）
  thumbnail.jpg    ← 仮のサムネイル（差し替える）
```

- **フォルダ名がそのまま URL** になる → `/articles/resume-writing/`
- フォルダ名は半角英小文字・数字・ハイフンだけ。内容がわかる英単語にする（例：`50s-it-career-change`）
- 公開後にフォルダ名を変えると URL が変わり、外部からのリンクや検索評価が切れるので変えない

## 2. 画像を用意する

画像は**記事と同じフォルダ**に置く。`public/` には置かない（最適化されない）。

| 用途 | ファイル名 | サイズ（横×縦） | 形式 |
|---|---|---|---|
| サムネイル | `thumbnail.jpg` | **1600×900**（16:9） | 写真は JPG |
| 本文の画像 | `figure-01.png`, `figure-02.jpg` … | **横1600px**、縦は自由（16:9 か 3:2 が扱いやすい） | 写真は JPG、図・スクショ・文字入りは PNG |

- **WebP への変換・リサイズは不要**。ビルド時に Astro が自動で行う（WebP 化、複数サイズの生成、遅延読み込み）。自分で WebP にすると二重圧縮で画質が落ちるので、元画像はできるだけ高画質で渡す
- サムネイルからは SNS 共有用の画像（1200×630）も自動で切り出される。**左右の端は切れる**ので、大事な要素は中央に寄せる
- 1ファイル数MBあっても問題ない（配信されるのは変換後の軽いファイル）
- 画像の権利：自分で撮影・作成したもの、AI生成、商用利用可の素材サイトのものだけを使う。ASP のバナーは ASP 指定のタグをそのまま使う

## 3. 本文を書く

```bash
npm run dev   # http://localhost:4321/articles/<フォルダ名>/ で確認
```

### frontmatter（ファイル先頭の `---` の間）

| 項目 | 必須 | 内容 |
|---|---|---|
| `title` | ○ | 記事タイトル（32文字前後が目安） |
| `description` | ○ | 要約。**120文字以内**（超えるとビルドエラー）。検索結果の説明文になる |
| `publishedAt` | ○ | 公開日（`2026-11-07` の形） |
| `updatedAt` | | 内容を更新した日 |
| `category` | ○ | `転職サイト` / `転職エージェント` / `ノウハウ` のどれか |
| `tags` | | 例：`[50代, 年収]` |
| `thumbnail` | | `./thumbnail.jpg` |
| `thumbnailAlt` | | サムネイルの内容の説明。装飾的な画像なら空でよい |
| `pr` | | アフィリエイトリンクを入れたら `true`（記事冒頭に PR 表記が出る） |
| `draft` | | `true` の間は開発環境だけに表示され、本番には出ない |

### 本文の書き方

| やりたいこと | 書き方 |
|---|---|
| 見出し | `## 大見出し` / `### 小見出し`（**`#` は使わない**。h1 はタイトルから自動で出る） |
| 画像 | `![画像の内容の説明](./figure-01.png)`（`[ ]` の説明＝alt は必須） |
| 他の記事へのリンク | `[職務経歴書の書き方](/articles/resume-writing/)`（**最後の `/` を忘れない**） |
| アフィリエイトリンク | `<AffiliateLink id="sample-agent" />`／ボタン型は `variant="button"` を付ける |
| コメント（表示されない） | `{/* メモ */}` |

- アフィリエイトの URL は `src/lib/affiliates.ts` に ID 付きで登録してから、記事では ID で参照する
- `<AffiliateLink>` を使っているのに `pr: true` がないと、**ビルドがエラーで止まる**（入れ忘れ防止）

## 4〜5. 公開前の確認

- `draft: false` にする
- `npm run build` がエラーなく通り、生成ページ一覧に `/articles/<フォルダ名>/index.html` が出ること
- `npm run preview` で表示を確認する（見出しが二重になっていないか、画像の alt、リンク切れ）

## 6. 他のページからリンクを張る

トップページのカード・タグは、**`href` を書いた項目だけがリンクになる**。`href` が無い項目は押せない表示で「準備中」と出る。記事ができたら、該当する項目に `href` を追加する。

| トップページの場所 | ファイル |
|---|---|
| あなたの悩みから探す | `src/components/top/TopWorry.astro` の `items` |
| 人気のサービス・ランキング | `src/components/top/TopService.astro` の `ranking` とボタン |
| 年代別の転職ガイド | `src/components/top/TopAgeGuide.astro` の `cards` |
| 職種別／年収・働き方／転職ノウハウのタグ | `src/pages/index.astro` の `categories` |

```ts
// 変更前（準備中）
{ Icon: IconTech, label: ['最新技術に', 'ついていけるか不安'] },
// 変更後（記事へのリンクになり、「準備中」が消える）
{ Icon: IconTech, label: ['最新技術に', 'ついていけるか不安'], href: '/articles/tech-catch-up/' },
```

- 職種別などの「詳しく見る」ボタンは、カテゴリ一覧ページ用の `moreHref` を書いたときだけ表示される
- 「転職サービス比較ランキングを見る」ボタンは、`TopService.astro` の `rankingHref` に記事の URL を書くとリンクになる

## 参考：Claude Code に図解を作らせる場合

Claude Code は写真のような画像は生成できないが、**グラフ・比較表・フロー図などの図解**は記事を読ませて作らせられる。

1. 「`src/content/articles/<フォルダ名>/index.mdx` を読んで、〇〇の部分を図解する SVG を作って」と頼む
2. SVG をブラウザ（ヘッドレス Chrome）で PNG に書き出してもらい、記事フォルダに `figure-01.png` として保存
3. 本文に `![図の説明](./figure-01.png)` を入れる

- 色はサイトのトークン（紺 `#06376a`、青 `#005fc2`、背景 `#eff8fd`）を指定すると統一感が出る
- 数値データ（年収・求人数など）は**出典を確認した値**を渡す。Claude に数字を作らせない
- サムネイルの写真は、AI画像生成サービスや素材サイトを使う
